# Open Clarifying Queries & Decisions (`AI/QUESTIONS.md`)

## 1. Metadata
- **Purpose**: Queue of open, clarifying, or underspecified questions regarding requirements, design intent, or missing factual information that require user feedback before implementation.
- **Owner**: AI Working Agent / Architect.
- **Update Trigger**: Updated whenever ambiguous requirements or missing data are detected during Phase 1 Understand.

## 2. Permitted Contents
- Question ID, priority, category (`CONTENT` / `ARCHITECTURE` / `DESIGN` / `DEPLOYMENT`).
- Specific question text with clear background context and trade-offs.
- Recommended option listed first with rationale.
- User answer once resolved.

## 3. Forbidden Contents
- Guesses or fabricated metrics/company names (violates `AGENTS.md § Never Assume`).
- Trivial yes/no questions that can be resolved by reading existing documentation.

## 4. Usage Rules for AI Agents
When encountering underspecified requirements, AI agents must log the question here and pause for explicit user approval per `AGENTS.md § When Unsure`.

## 5. Relationship to Core Documents
- **Relationship to `AGENTS.md`**: Implements `AGENTS.md § Never Assume` and `When Unsure`.
- **Relationship to `MASTER_PLAN.md`**: Resolves ambiguities before starting affected milestones.
